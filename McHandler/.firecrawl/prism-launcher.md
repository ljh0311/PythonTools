# Prism Launcher

An open-source Minecraft launcher with the ability to manage multiple
instances, accounts and mods. Focused on user freedom and free
redistributability.

[Download](https://prismlauncher.org/download/linux)

![Prism Launcher screenshot showing off various different modpacks and instances](https://prismlauncher.org/_astro/linux_light.jDSJ-320_Z2wzXS8.png)![Prism Launcher screenshot showing off various different modpacks and instances](https://prismlauncher.org/_astro/linux_dark.h_D7aY-K_2o8X8m.png)

## Features

### Modpack Management

Prism Launcher makes it easier to install and launch modpacks, while
keeping them clean. You no longer need to manually install and update
modpacks as Prism Launcher can do this for you.

![Prism Launcher screenshot showing the modpack installation user-interface](https://prismlauncher.org/_astro/pack-install_light.BmIXRhrQ_Z24gEaX.png)![Prism Launcher screenshot showing the modpack installation user-interface](https://prismlauncher.org/_astro/pack-install_dark.DUO5iW2q_Z7iboK.png)![Prism Launcher screenshot showing the modpack updating user-interface](https://prismlauncher.org/_astro/pack-update_light.DQ2IXg8Z_ZqcwLC.png)![Prism Launcher screenshot showing the modpack updating user-interface](https://prismlauncher.org/_astro/pack-update_dark.BYX7DikN_Zrgust.png)

### Mod Management

Sick of constantly finding and re-adding that one mod you need? Prism
Launcher interfaces directly with Modrinth and CurseForge, allowing you to
update or install individual mods easily.

![Prism Launcher screenshot showing the mod installation user-interface](https://prismlauncher.org/_astro/mod-install_light.CGJuBk7W_lGTQh.png)![Prism Launcher screenshot showing the mod installation user-interface](https://prismlauncher.org/_astro/mod-install_dark.CT2tHrB6_Z22vq05.png)![Prism Launcher screenshot showing the mod updating user-interface](https://prismlauncher.org/_astro/mod-update_light.Clfo4Pji_ZFdOoA.png)![Prism Launcher screenshot showing the mod updating user-interface](https://prismlauncher.org/_astro/mod-update_dark.C7zA30XZ_Z1gzikv.png)

### Instance Management

Prism Launcher allows you to create and manage multiple instances of
Minecraft, each with its own settings, mods, and configurations. This
means you can easily switch between different setups without any issues.

![Prism Launcher screenshot showing the instance management user-interface](https://prismlauncher.org/_astro/instance-settings_light.C1emvG9A_ZcI0Ja.png)![Prism Launcher screenshot showing the instance management user-interface](https://prismlauncher.org/_astro/instance-settings_dark.VwPQ_hgz_Zg59QO.png)

### Lightweight and Customizable

You don't need an embedded web browser as a game launcher. Prism Launcher
is built with the Qt toolkit, requiring very few system resources to run.
It also lets you customize the menu and supports custom themes.

![Prism Launcher screenshot showing a themed user-interface](https://prismlauncher.org/_astro/themes_dark.D786xeAp_7IL84.png)
